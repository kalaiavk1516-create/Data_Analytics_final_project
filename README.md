# Population Group-wise Deposits Analysis Using Python

## Project Overview

This project analyzes population group-wise deposit data using Python. It explores deposit amounts, number of accounts, and number of offices across years, states, districts, regions, and population groups.

## Objectives

* Understand and clean the dataset.
* Identify and investigate missing values and duplicate records.
* Perform statistical analysis and aggregation.
* Compare deposits across states, regions, and population groups.
* Analyze yearly trends.
* Create visualizations to communicate findings.
* Generate evidence-based business insights.

## Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Google Colab

## Analysis Performed

* Data inspection and type validation
* Missing-value and duplicate checks
* Aggregation using sum, min, max, mean, median, and count
* Group-wise analysis using groupby
* Exploratory Data Analysis
* Data visualization using 10 charts

## Dataset

The dataset contains year, state, district, region, population group, number of offices, number of accounts, and deposit amount.

## Results

Key findings will be added after running the analysis and validating the results.

## Limitations

Missing values may affect aggregate results. The unit of the deposit amount and the completeness of the latest year's data should be verified before drawing final conclusions.
